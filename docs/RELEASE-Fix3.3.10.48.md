## 本版修复

### 生成失败恢复

- 保存服务端 SSE 的 request_message_id，将编辑消息精确关联到失败分支的用户消息；regenerate 关联失败 assistant，completion 继续要求同会话、同父 assistant。缺少确切 ID 时不猜 ID、不按提示文本模糊匹配。
- compact / passthrough 恢复提示从纯页面 Map 扩展为带 TTL 的 localStorage 提示，页面重建后仍可读取。只保存会话键、消息 ID、模式、失败计数、到期时间，不保存用户提示、工具参数或授权。compact 10分钟、passthrough 60秒，最多32个条目；成功清理、消费后删除。
- 恢复提示不是授权，不能执行工具；无自动重放生成请求。localStorage 不可用时退化为当前页面内存恢复。跨标签 localStorage 消费不具备事务语义，但提示仅控制文本精简，绝不允许复用工具授权。
- 正常请求中，描述符 JSON 超过16000字符时也去除冗长描述，保留工具身份、必填字段、全部 schema 约束；执行授权仍使用完整描述符。该阈值是字符数，不是模型 token 限额，不裁剪用户原始任务。
- 生成错误提示说明：重开页面不清理云端历史，重复失败应使用简短交接摘要新建会话；不把累计 token 计数误报为单次上下文长度。

### MCP 503 与安全重试

- 同一授权调用内部，初始化遇到明确 HTTP 502/503/504 最多额外尝试一次，延迟350ms并响应取消；在成功初始化后才发送 tools/call。
- 初始化重试耗尽明确返回未发送工具、不可自动重放，避免进入前端第二套重试。
- 前端不再对已消费授权的 MCP 调用使用原 ID 重试；外层只读重试也要求明确 not_dispatched 且 retrySafe=true，不能用新 ID 绕过结果不明限制。
- tools/call 结果不明时不自动重放，包括 run_command、写文件、上传等。后台授权、指纹、单次调用消费、上传检查保持逐字节不变。

### 任务进度和停止

- 工具发出前保存待确认 ID，工具返回即保存结果，步骤完成即 checkpoint；不再等每4步才保存普通只读结果。高频文本/思考流仍内存缓冲。
- 持久化保留 callId，累计工具计数按结果账本更新；恢复摘要列出未确认调用，要求核查现有产物/工具结果后再发新命令。
- 增加页面执行者标识、单调修订号及过期写拒绝；同源页面支持 Web Locks 时串行化 trace 读改写，避免标签间覆盖。不可用时保留既有单页面锁和过期写检查，但不声称获得跨页面事务保证。
- 停止前先刷新缓冲文本/思考，再写终态。pagehide 与用户停止分开记录；保存 requested / confirmed / stale_rejected / failed 的有界诊断，便于定位未落盘状态。
- **关闭页面仍会暂停页面内 Agent，不会变成后台自动续跑。** 已发送到外部工具的命令可能继续运行；重新开始前应核实结果。本版不声称找到了先前那次中断的唯一触发原因。

### NUL 路径

- MCP search_files 且工具 schema 支持 exclude 数组时，增加根层及子目录大小写不敏感 NUL 排除，保留用户既有查询和排除项；结果明示这些条目未搜索。不删除文件，不把搜索错误改成成功。
- 现场只读验证：在原报错目录使用相同排除规则，ripgrep 正常完成（0匹配、无 I/O 错误）。这仅证明该目录遍历不再被 NUL 阻断，不等于所有文件系统错误都已解决。
