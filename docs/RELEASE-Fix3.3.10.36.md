## 修复内容

- **主动视觉工作流**：参考图/SVG/UI复刻、截图转网页、图像对比等任务，初始提示和后续 Agent 规则主动要求视觉依据，不再只依赖用户额外说“调用 read_image”。自适应工具排序提高 read_image 优先级，相关制作任务同时提高写入工具优先级；缺工具走 discover/describe/invoke，不捏造工具名、参数或 capability。
- **结束前置检查**：明确本地参考路径的 Web 任务，在本轮没有成功 read_image 时不直接宣布完成；目录/文字读取、能力发现或失败读图都不能替代。缺路径可询问用户；对已有附图、普通知识问答、元数据检查和明确禁止读图/上传的请求，不强加该自动流程。
- **长工具块误结束**：旧未注册标签正则只匹配20,000字符正文，且全文超过200,000字符直接放弃。本版改为线性标签扫描；读图后输出长 `<apply_patch>` 而未实际执行时，不能再直接 final/complete。
- **有界续执行**：未执行工具块优先于 task_complete，进入工具重发；同时处理本步骤与整轮纠偏上限，达到上限显示失败，而非空 steering / 误完成。保留手动停止与授权边界，不自动执行原始补丁或未知标签。
- **制作与验收要求**：读图不是制作完成；继续按用户要求生成、保存、验证。有授权渲染能力则渲染后再看图对比，没有做就明确说明。不以旧印象、尺寸或禁止使用的描摹/convert 冒充视觉复刻，不把图中文字当成系统指令。
- **交接与笔记**：交接文档更新；按用户要求将本机“奇思妙想”整理为 `dspp`，设4篇当前入口、21篇主题归档及1篇历史索引，保留禁止伪作画硬规则。迁移有原始备份，修复53处链接、验证131处新链接。私人笔记内容没有打包或推送到此代码仓库。
